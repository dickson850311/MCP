## 求解器与结果

| 项 | 值 |
|---|---|
| 求解类型 | 稳态、单相、Flow And Heat |
| 辐射 | DO，每 5 步更新 |
| 并行 | 报告记录 8 进程（脚本未设置，GUI 文件→选项→对象相关 设） |
| 最大迭代 | 03 设 500；05 改 **300** |
| 监控点收敛 | 开，温度精度 0.1 ℃，残差阈值 30 |
| 实际计算 | 300 步，约 20 min 59 s |
| 末步 T 残差 | **107**（未达 30） |
| 最后 10 步监控点变化 | ≤ **0.195 K** |
| FPC 最高 / 平均 | **107.33 / 96.38 ℃** |
| Frame 01 最高 / 平均 | 106.09 / 34.89 ℃ |
| BOX_SOLID 最高 / 平均 | 105.14 / 59.02 ℃ |
| DIFF 最高 | 97.20 ℃ |
| BEF 最高 | 96.59 ℃ |
| DBEF 最高 | 95.73 ℃ |
| REF 最高 | 92.24 ℃ |
| LGP 最高（体数据图） | 83.9 ℃；最低 25.0 ℃ |

**收敛判定**：300 步只是上限，残差 107 未达 30，温度仍在缓慢上升；199→300 步热点普遍再升约 4 K。该结果只能作为“偏保守偏低”的中间结果，不能作为设计定案。

## 培训 12.3″ 样机参考（不是 QR-V23 结果）

| 项 | 培训值 |
|---|---|
| LED | 3.1 V × 120 mA ≈ 0.3 W 输入，热损耗 **222 mW/颗** |
| 辐射 | 未开辐射 |
| LED 最高 | **59 ℃** |
| 屏面 | 40+ ℃ |
| 背面 | 45–46 ℃（实测 42–43 ℃） |
| 辐射影响 | 约 1–2 ℃ |
| FPC | 含铜 20% → k≈25–26 W/(m·K) |
| 网格 | 内部 0.4 mm / 外部 3 mm，130 万→196 万 |
| 求解域 | 宽 30%、正高 200%、负高 50%、厚 300% |
| 瞬态 | 3600 s / 200 步 / 每步迭代 20 次 / 每 20 步存盘 |

> **不要把 59 ℃ 当作 QR-V23 的期望值。** 两者 LED 型号、热功率、辐射开关、网格都不同；QR-V23 是 9.096 W 总热功率、DO 辐射、0.1/6 mm 网格。

## 数据缺口

1. LED 驱动电流：100 mA（9.096 W）还是 120 mA（11.508 W），需规格书/实测确认。
2. FPC 实际含铜体积分数：现按 20% 取 k=25；不同叠层需改正交各向异性。
3. 叠层界面接触热阻：当前用等效方块，界面热阻被抹平。
4. 设计限值：LED 结温上限、LGP 平面度、膜片翘曲、屏面温度上限。
5. 屏面/导光板实体监控点：现两个监控点落在流体，需在实体内部重建。
6. EC 原生云图：批处理只出体数据重构图；原生云图需 GUI 后处理。
