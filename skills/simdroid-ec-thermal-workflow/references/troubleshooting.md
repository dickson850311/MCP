# 伏图 EC 故障与踩坑

## 1. `import IBE` 失败 / 模块找不到

**现象**：`ModuleNotFoundError: No module named 'IBE'` 或 `ImportError`。

**根因**：cwd 不在 `<安装根>\script\`，或 01–08 的 IBE 脚本误用了系统 Python。

**处理**：

```powershell
$root = "D:\Simdroid Electronic Cooling V2026.7.3"
Set-Location "$root\script"
& "$root\bin\python.exe" "D:\path\to\script.py"
```

或直接用 `run_ec.ps1`。不要用系统的 `python.exe`。

## 2. `模型中存在非正交元件，无法剖分网格`

**现象**：

```text
模型中存在非正交元件，无法剖分网格 @FlexPart__Assembly# ...
剖分网格失败
```

**根因**：伏图区域/八叉树网格是笛卡尔网格，要求导入体所有面垂直于坐标轴。STEP 中许多薄膜/泡棉件局部坐标系旋转，`LocalSize` 与全局包围盒不一致。

**已验证的解法**：

- 按 `bbox.csv` 把 22 件薄壳/异形件替换为等效正交 `Cube`（`03_build_model.py` 的 `OFFEND`），其余保留 CAD。
- 删掉 <0.1 mm 的超薄辅料（`04_thin_cleanup_mesh.py`）。
- 让结构重导一版“仿真用 STEP”：实体落在全局坐标系、去圆角/斜边、按层合并。
- GUI 里“转换几何 → 体素化 / 平展拔模角 / 单一元件”也可，但不可脚本化。

**不要试**：

- 把导入体 `LocalMethod` 改成 `Octree Based`：实测内核直接崩溃。
- 只改特征提取/扩展开关/各向异性/更细最小尺寸：均无效。
- 对全部导入体直接常规网格：会失败。

## 3. 网格量失控 / 网格质量差

**现象**：网格几百万、剖分时间长、长宽比极大。

**根因**：薄壳件按实体剖分；0.05 mm 最小尺寸 + 大量薄片。

**处理**：

- 03 先换等效方块，04 删 <0.1 mm 辅料。
- 全局最小从 0.05 放到 0.1 mm（05 的做法）；最大 6 mm。
- 关键散热路径用体积区域加密，不要全局 0.05。
- 报告里记录 `最大长宽比`、`最大非正交度`、`劣质面数`；长宽比 >100 不一定不可用，但要说明来源。

## 4. 04/05 删件后 07/08 取不到结果

**现象**：`匹配到的对象: {}`、`无数据: ...`。

**根因**：删件后零件名/标签变了，或 `TARGETS` 前缀不匹配。

**处理**：

- 先跑 08，生成 `temp_all` 和 `温度结果汇总.csv`；用汇总里的“零件标签”核对。
- 改 07 的 `TARGETS` 前缀；改 11 的 `g(prefix)`。
- `07` 用 `startswith`，标签前空格/下划线差异会导致漏匹配。

## 5. 监控点恒为环境温度

**现象**：`MP_LGP`/`MP_PANEL` 从第 1 步起就是 25.7 ℃。

**根因**：监控点落在流体单元，不在固体。

**处理**：

- 把监控点移到实体内部（LED 正中心、LGP 板内、面板实体内部）。
- 或不用监控点判板面温度，改用 `08` 的体数据统计。
- 报告里明确写“该监控点落在流体，不用于判定”。

## 6. 300 步后残差仍高

**现象**：`Residual(T) = 107`，阈值 30；温度仍在缓慢上升。

**根因**：只跑满 `MaxIteration=300`，不是收敛。

**处理**：

- 加步到 400–500；或调松弛（T 0.3 / U 0.5 / P 0.5 逐步试）；或放宽网格。
- 报告写“未收敛，结果偏保守偏低”，不要把 300 步结果当定案。
- 不要伪造“残差已达标”。

## 7. `11_report.py` 报 `add_picture` 文件不存在

**现象**：`FileNotFoundError: ...\report_img\map_lgp.png`。

**根因**：09/10 没有生成四张图之一；原 `10_maps.py` 只生成 `map_top.png` 和 `chart_strip.png`，`map_lgp.png` 是另外生成的。

**处理**：本 Skill 的 `10_maps.py` 已补 LGP 图生成；先跑 09 和 10，再跑 11。四张图：

```text
chart_monitor.png
chart_parts.png
chart_strip.png
map_lgp.png
```

## 8. 报告数值/零件名对不上

**现象**：`KeyError: 'BOX_DBEF'` 或报告表里是旧产品名。

**根因**：`11_report.py` 是 QR-V23 案例模板，组件前缀、封面、日期、工序写死。

**处理**：

- 换产品必须改封面产品名、工程路径、日期、工序、组件前缀。
- 数值以 `温度结果汇总.csv` 为准；不要保留旧报告的硬编码数字。
- 如果新项目没有同名件，先改 `g(prefix)` 或删掉对应章节。

## 9. PowerShell 退出码/路径问题

- `run_ec.ps1` 用 `exit $LASTEXITCODE` 透传；`run_all_ec.ps1` 在非 0 时抛错。
- 脚本路径用绝对路径；cwd 会被 `run_ec.ps1` 切到 `script\`。
- 安装根不是默认路径时，设 `$env:EC_INSTALL_ROOT`。
- 配置文件不是默认路径时，用 `-Config` 或 `$env:EC_CONFIG`。

## 10. 原生云图 vs 体数据图

- 批处理模式不能生成 EC 原生云图；`10_maps.py` 用 `temp_all` 的体数据画俯视/条带/LGP 图。
- 需要原生云图时，在 GUI 打开 `files.v5`，后处理里出平面/表面云图。
- 报告里要注明“体数据重构，不是软件原生渲染”。

## 11. 结果口径混淆

- QR-V23 代码包：9.096 W、DO、300 步、FPC 107.33 ℃、残差 107 未收敛。
- 培训 12.3″：222 mW/颗、未开辐射、LED 59 ℃。
- **不能把 59 ℃ 当 QR-V23 的期望值，也不能把 107.3 ℃ 当 POC 冷热冲击结果。**
